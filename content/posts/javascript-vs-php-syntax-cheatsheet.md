## Learning new programming languages

There are core concepts that carry over to virtually all programming languages. Loops, functions, and variables are part of (nearly?) every modern language. What's more, many _approaches_ one takes to languages largely carry over as well. Knowing what you want to do and how you want to do it is 80% of the art of computer science. The other 20% (which takes at least 50% of the time!) is actually writing the code in the vocabulary and grammar of a given language and getting it to work. The bright side of all of this is that if you really know computer programming, it doesn't take that long to learn a new language. You study syntax, grammar, and a few particularities like memory management and before you know it, you're programming in the new language (crudely, of course, but still). All of this goes to say that it's not _all that_ hard to learn a new language, but it does take time.

## Switching back and forth between PHP and JavaScript

On a typical LAMP server (Linux, Apache, MySQL, and PHP) the developer spends most of their time in the realm of JavaScript and PHP. They serve different needs, and they work really well together. They even interact -- JavaScript can call PHP with AJAX, and PHP can communicate back or even directly write out JavaScript code. There are some underlying major differences between the two. For instance, PHP is actually class based while JavaScript relies on prototypal inheritance. But it's the little things that trip you up. All similarities aside, switching back and forth is a real bitch. Thus I present the PHP / JavaScript Syntax Cheatsheet. Only the _differences,_ those nasty little subtleties that drive me crazy, will make it into the list.
