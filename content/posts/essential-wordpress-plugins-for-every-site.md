## [4\. UpDraft Plus](https://wordpress.org/plugins/updraftplus/)

This plugin (freemium, despite the "plus" in the free version's name) makes backing up your entire WordPress site easy andÂ automatic. It helpfully breaks apart backups into database, theme files, uploads,Â etc. so that you only have to restore what's needed. More impressively, it seemlessly integrates with numerous online storage solutions including AWS and Dropbox. That feature has been hugely popular with my clients who like seeing (but not touching!) their site backups. The premium version adds free backup storage.

## [3\. Caldera Forms](https://wordpress.org/plugins/caldera-forms/)

There are a lot of viable options for your WordPress sites' email form builder. Contact Form 7 is the standard here, but I prefer Caldera for it's quick form-builder and intuitive interface. The developers have included plentiful hooks for extendability, although there is not particularly good documentation and I've had to trace my way through their code to find what I've needed. The pay model is based around add-ons and bundles, but for serious developers you're mostly paying to support their great work and save some time in the process.

## [2\. WordFence](https://wordpress.org/plugins/wordfence/)

One of the top security plugins, this enables a whole gamut of protections for sites. Even small, low-traffic sites are prone to hacking. A freemium plugin is no guarantee, but it does block some of the most common techniques like brute-force attempts to "guess" the password. The plugin is frequently updated--for instance, it already disables username probing via the WordPress API which was only recently introduced. The premium version ($99/yr) enables automatic IP blacklisting drawn from their ongoing database.
