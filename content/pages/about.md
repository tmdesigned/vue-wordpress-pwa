## About this site

I created this site in 2019 as a headless WordPress implementation coded in Vue.js. It was a Progressive Web App, pulling posts on demand from the WP API and serving them out of a VUEX store. The site was hosted on an EC2 instance at AWS with a Let's Encrypt SSL.

In 2026, Bitnami was removed from the AWS catalog, and a severe PHP vulnerability was disclosed which together made updating essential and impossible. 

I migrated the site to GitHub pages with Decap used to manage local markdown files as the source of data, completely eliminating WordPress as a dependency and removing the need for me to directly manage infrastructure security for a mostly static site.
