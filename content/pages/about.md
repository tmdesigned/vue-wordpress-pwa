## About this site

I created this site in 2019 as a headless WordPress implementation coded in Vue.js. It is a Progressive Web App, pulling posts on demand from the WP API and serving them out of a VUEX store. The site is hosted on an EC2 instance at AWS with a Let's Encrypt SSL.
